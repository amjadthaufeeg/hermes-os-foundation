## FC-01 — Missing Credential

| Field | Value |
|---|---|
| Failure | Remove synthetic B2_READER_KEY_ID mount |
| Component | B2 reader credential (P2 equivalent) |
| Expected | Container starts, B2 auth fails at first backup verification attempt, health shows degraded for B2, mutations remain DISABLED |
| PASS if | Container healthy, B2 check fails, no mutation enabled, no staging fallback, no crash |
| FAIL if | Container crashes, mutations enabled, staging credentials used |
| Prerequisite | Test-B running healthy |
| Change required | Remove B2_READER_KEY_ID mount line from compose, recreate |
| Restore | Restore mount line, recreate |
| Risk | LOW |
| Type | INFRASTRUCTURE FAIL-CLOSED |

### Commands

```bash
# VPS TERMINAL
cd /docker/hermes-product-os
# Comment out B2_READER_KEY_ID mount in docker-compose.test-b.yml
docker compose -f docker-compose.test-b.yml config -q
docker compose -f docker-compose.test-b.yml up -d --no-deps --force-recreate hpos-test-b
sleep 10
docker ps --filter name=hermes-product-os-test-b --format '{{.Names}} {{.Status}}'
docker exec hermes-product-os-test-b python3 -c "import urllib.request; print(urllib.request.urlopen('http://localhost:8080/api/health').read().decode())"
# Restore mount line after test
docker compose -f docker-compose.test-b.yml up -d --no-deps --force-recreate hpos-test-b
```
