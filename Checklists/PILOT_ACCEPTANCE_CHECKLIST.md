# First Pilot Acceptance Checklist

## Before build
- [ ] Backup branch or tag exists.
- [ ] Task is small and presentation-only.
- [ ] Change contract is approved.
- [ ] Allowed files are limited.
- [ ] Protected behavior is explicit.
- [ ] One active builder is assigned.

## Before preview
- [ ] Automated checks passed or existing failures are documented.
- [ ] Candidate is committed to GitHub.
- [ ] Claude review completed.
- [ ] Required findings are resolved.
- [ ] Replit identifies branch and commit.
- [ ] Preview does not use production data.

## Amjad review
- [ ] Requested visible issue is fixed.
- [ ] Existing workflow still works.
- [ ] Mobile and desktop were checked.
- [ ] Nothing unrelated changed.
- [ ] Result is approved or precise feedback is recorded.

## Completion
- [ ] Merge approval recorded.
- [ ] Rollback method documented.
- [ ] Learning record completed.
- [ ] Any discovered regression has a permanent guard.
