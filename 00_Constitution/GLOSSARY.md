# Glossary

**Active builder** — The only agent permitted to write code on a task branch at a given time.

**Change contract** — The binding task boundary: objective, allowed files, protected areas, acceptance criteria, checks, and stop conditions.

**Locked decision** — A product or architecture decision that cannot change without explicit approval from Amjad.

**Regression** — A previously working or fixed behavior that becomes broken again.

**Source of truth** — The authoritative version. GitHub is the code source of truth; approved knowledge documents are the decision source of truth.

**Preview** — A temporary running environment showing a specific committed branch and commit.

**Evidence** — Test output, diff, commit, screenshot, runtime check, review result, or other verifiable proof.

**Scope violation** — Any change outside the approved contract.

**Stop condition** — A circumstance requiring the builder to pause and return control to Hermes.
