# Replit Preview Protocol

Replit is a live review environment, not the source of truth.

## Requirements
- Preview a named GitHub branch and committed SHA.
- Display branch, commit, build time, and environment where practical.
- Use preview secrets and preview or mock data.
- Never connect to production databases by default.
- Direct code editing in Replit is prohibited by default.
- Any emergency Replit edit must be committed back to the approved branch and re-reviewed.
- Preview should be refreshed after approved corrections.
- Preview environment should be archived or removed after merge.
