# Model Routing Rules

Routing combines task type, risk, repository scope, behavior sensitivity, prior project performance, cost, and availability.

## Initial policy
- Kimi K3: default for substantial feature and broad multi-file implementation.
- Codex: default for surgical changes and sensitive behavior preservation.
- Claude Code: independent reviewer and architectural challenger.

## Evidence requirement
Routing changes must cite scorecard evidence and sample size. General benchmark claims alone do not change project policy.

## Governance priority
Intelligence recommendations never override permissions, locked decisions, approval gates, or stop conditions.
