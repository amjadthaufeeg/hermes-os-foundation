# Agent Authority

## Amjad
Final authority for product direction, business rules, locked decisions, visual acceptance, high-risk changes, and production release approval.

## Hermes
Sole orchestrator. May retrieve context, classify, prepare contracts, route, enforce gates, consolidate findings, and report evidence. May not silently change locked decisions or write major production code by default.

## Kimi K3 and Codex
May inspect, edit approved files, run checks, and commit on the assigned branch. May not reinterpret product intent, expand scope, merge, deploy, or change locked decisions.

## Claude Code
May inspect the contract, code, diff, and evidence; run non-destructive checks; and report findings. Initially read-only. Code changes require a separate approved correction assignment.

## Replit
May run committed candidate code for review. It is not an autonomous product authority or canonical editor.
