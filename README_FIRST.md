# Hermes OS v1.0 Foundation Pack

## What this package is

Hermes OS is the control system for how Amjad, Hermes, builders, reviewers, GitHub, Replit, tests, and production environments work together.

It is not a software operating system like Windows or macOS. It is an operating model made from rules, templates, registers, and gates that Hermes must follow.

## Final role model

```text
Amjad        = product owner and final authority
Hermes       = sole orchestrator and evidence manager
Kimi K3      = primary builder for substantial implementation
Codex        = precision builder, fallback, and challenger
Claude Code  = independent reviewer, initially read-only
GitHub       = authoritative source of truth
Replit       = live preview of committed candidate code
Tests        = mandatory quality gate
```

## The seven layers

1. Knowledge OS — defines what is true.
2. Task OS — turns requests into controlled tasks.
3. Engineering OS — builds, reviews, previews, merges, and rolls back.
4. Governance OS — defines authority, permissions, approvals, and auditability.
5. Learning OS — prevents repeated mistakes and improves routing.
6. Operations OS — controls staging, production, monitoring, incidents, and recovery.
7. Intelligence OS — improves model routing, confidence, cost, and escalation using evidence.
