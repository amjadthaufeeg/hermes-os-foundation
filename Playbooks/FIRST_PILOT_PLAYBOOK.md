# First Pilot Playbook

1. Select one visible, low-risk issue.
2. Retrieve relevant design and locked decisions.
3. Classify as VISUAL_ONLY and R1.
4. Draft and obtain approval for the change contract.
5. Create a feature branch from a known base commit.
6. Assign one builder.
7. Run baseline checks.
8. Implement the smallest sufficient change.
9. Run automated checks and commit.
10. Claude reviews read-only.
11. Hermes approves required corrections.
12. Builder applies only approved corrections.
13. Re-run checks and commit.
14. Publish Replit preview with branch and SHA.
15. Amjad tests appearance and existing behavior.
16. Merge only after approval.
17. Do not auto-deploy to production.
18. Complete the learning record and scorecards.
